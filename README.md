# 개인정보 마스킹 도구 (로컬 / macOS)

인터넷 연결 없이 **내 컴퓨터 안에서만** 동작하는 개인정보 마스킹 GUI 프로그램입니다.
원본은 그대로 두고, 파일명에 `_masked`가 붙은 **사본**을 만들어 마스킹합니다.

## 구성 파일

| 파일 | 역할 |
|------|------|
| `masking_app.py` | 창이 뜨는 GUI 본체 |
| `masking_engine.py` | 번호류 민감정보 탐지·마스킹 + 이름/주소 문자열 마스킹 |
| `ner_engine.py` | 이름·주소 자동 인식(GLiNER 다국어 모델 + 한/영/일 주소 정규식) |
| `file_handlers.py` | 파일 형식별(텍스트/Word/Excel/PDF/이미지) 처리 |
| `requirements.txt` | 필요한 라이브러리 목록 |
| `설치_및_실행.command` | 더블클릭으로 실행하는 macOS 런처 |

## 설치 및 실행 (가장 쉬운 방법)

1. 위 5개 파일을 한 폴더에 모아둡니다.
2. 터미널에서 실행 권한을 한 번만 부여합니다:
   ```bash
   chmod +x "설치_및_실행.command"
   ```
3. `설치_및_실행.command` 를 **더블클릭**합니다.
   - 처음 실행 시 자동으로 가상환경을 만들고 라이브러리를 설치합니다(1~2분).
   - 이후에는 더블클릭하면 바로 프로그램이 뜹니다.

> "확인되지 않은 개발자" 경고가 뜨면: 파일을 **우클릭 → 열기** 를 선택하세요.

## 사용 방법

1. **파일 추가** — 파일을 목록 칸에 **끌어다 놓거나(드래그 앤 드롭)** [파일 추가] 버튼으로 선택 (여러 개 가능)
2. **민감정보 유형 체크** — 실행할 때마다 원하는 항목만 선택
   (주민등록번호 / 전화·휴대폰 / 이메일 / 카드번호 / 계좌번호 / 여권번호)
3. **이름·주소 자동 인식** — 이름/주소 체크 + 인식 언어 선택(한국어/English/日本語)
   - 처음 한 번 **[이름·주소 모델 준비]** 버튼으로 모델 다운로드(인터넷 필요)
4. **마스킹 레벨 선택**
   - **완전 가리기**: `910101-1234567` → `●●●●●●-●●●●●●●`, `홍길동` → `●●●`
   - **부분 가리기**: `910101-1234567` → `910101-1●●●●●●`, `홍길동` → `홍●●`
5. **사본 저장 폴더 선택**
6. **마스킹 실행** → `원본명_masked.확장자` 사본 생성

## 이름·주소 자동 인식 (GLiNER)

- 한국어·영어·일본어의 **이름(인물)** 과 **주소/지명** 을 자동으로 찾아 가립니다.
- 동작 방식: **GLiNER 다국어 PII 모델**(한·영·일을 하나의 모델로 처리) + 한/영/일 **주소 정규식** 보강.
- **최초 1회** GUI의 `[이름·주소 모델 준비]` 버튼을 누르면 모델을 내려받습니다
  (인터넷 필요, 수백 MB). 이후에는 **완전 오프라인**으로 동작합니다.
- 인식 엔진(`gliner`)은 PyTorch를 함께 설치하므로 용량이 큽니다(처음 설치 시 시간이 걸림).
- 이름/주소를 사용하지 않으려면 체크를 해제하면 되고, 그 경우 모델 설치도 필요 없습니다.
- 참고: 이전에 쓰던 Stanza는 **한국어 NER을 제공하지 않아** GLiNER로 교체했습니다.

## 지원 형식

- 텍스트: `.txt .md .csv .tsv .log .json`
- 문서: `.docx` (Word), `.xlsx` (Excel), `.pdf`
- 이미지: `.png .jpg .jpeg .bmp .tiff`

## 형식별 동작 차이

- **텍스트·Word·Excel**: 선택한 레벨(완전/부분)대로 문자만 치환, 서식 유지.
- **PDF**: 보안을 위해 해당 텍스트를 **실제로 삭제(redaction)** 하고 검은 박스로 덮습니다.
  복사-붙여넣기로도 복원되지 않습니다. (레벨과 무관하게 완전 제거)
- **이미지**: OCR로 글자 위치를 찾아 가립니다. **부분 가리기** 선택 시 각 단어의
  첫 글자만 남기고 나머지를 덮습니다(완전 가리기는 단어 전체를 덮음).

## 정확도 조절 (과다/과소 마스킹 해결)

- **탐지 강도**: 공항·일반명사까지 가려지면 **약하게(정확)**, 놓치는 게 많으면 **강하게(많이)**.
- **제외 단어**: 절대 가리지 말 단어를 쉼표로 입력(부분일치). 공항·항공·터미널 등
  여행 관련 단어는 **기본으로 제외**되어 있습니다.
- 이름·주소 라벨을 좁게(person/address) 사용해, 도시·공항 같은 일반 지명의 오탐을 줄였습니다.

## 이미지 마스킹 추가 설치 (선택)

이미지(사진) 처리는 OCR 엔진 `tesseract`가 필요합니다.
[Homebrew](https://brew.sh)가 있다면 터미널에서:

```bash
brew install tesseract tesseract-lang
```

`tesseract-lang`을 설치하면 한글 인식(`kor`)이 가능합니다.
이미지를 다루지 않는다면 설치하지 않아도 됩니다.

## 한계 (꼭 읽어주세요)

- 번호류(주민번호·전화·이메일·카드)는 **정규식**으로 정확히 잡습니다.
- 이름·주소는 **AI 모델(NER)** 로 잡지만 100% 정확하지는 않습니다. 흔치 않은
  이름, 약식 주소, 외국식 표기는 놓칠 수 있습니다.
- 부분 마스킹은 일부 정보가 남으므로, 외부 공유 전에는 **완전 가리기**를 권장합니다.
- 자동 마스킹 후에는 사본을 **눈으로 한 번 확인**하세요. 탐지를 100% 보장하지 않습니다.

## 문제 해결

**이름·주소 모델 준비 시 `Cannot find ... ner, default` 오류**
한국어 NER을 제공하지 않는 옛 엔진(Stanza)에서 나던 오류입니다. 현재는 GLiNER로
교체되어 한·영·일 모두 동작합니다. 엔진이 바뀌었으니 터미널에서 새 엔진을 설치하세요:

```bash
cd "<이 폴더 경로>"
PYTHONIOENCODING=utf-8 ./.venv/bin/pip install --no-compile gliner
```

**이미지 마스킹 시 `tesseract is not installed` 오류**
이미지(사진) 처리에는 OCR 엔진이 필요합니다. `brew install tesseract tesseract-lang` 실행 후 다시 시도하세요.

**pip 설치 중 바이트컴파일 오류 (`encode() ... must be str, not None` 등)**
`설치_및_실행.command`가 `--no-compile`을 사용하도록 되어 있어 다시 받으면 해결됩니다.
이름·주소 엔진 설치가 실패해도 번호류 마스킹은 정상 동작합니다.

## 안전성

- 모든 처리는 로컬에서만 이루어지며 네트워크를 사용하지 않습니다.
- 원본 파일은 절대 수정되지 않습니다(읽기만 함).
